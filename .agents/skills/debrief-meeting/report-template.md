to list is dropped.

```

## Topics

**<n>. <topic> (#<issue> / new issue / excluded)**

- Written: <inbox path | issue comment link | body edited | issue link | none>

## New issues
- <issue link> — <title>

## Skipped
- #<issue>: open PR, no checkout on its branch

## Mid-ticket
- #<issue>: inbox written into a checkout with uncommitted changes

## Excluded
<topic> (<product>); <topic> (<product>)

## Failed

```
